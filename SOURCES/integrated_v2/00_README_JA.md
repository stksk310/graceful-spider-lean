# A∞と六腕七腕の統合証明

最初に **PROOF_BOOK_JA.pdf** を読む。共通の初等補題、A∞の完全証明、六腕、七腕、有限証書の順に、一冊の中で全整数の論証を追える。編集用原稿は `proofs/` と `PROOF_BOOK_JA.md`、組版ソースは `PROOF_BOOK_JA.tex` にある。

## 方針と役割

A∞は三腕のハブ0α部品を供給する存在定理である。一般化Fusionは、条件を満たす部品の接合則である。本書では区間挿入を一度証明し、葉への挿入をA∞の腕延長、ハブへの挿入を六腕・七腕の接合に使う。接合則から部品の存在を推測しない。

端点指定道とα反転も共通章で一度だけ証明する。最大腕6以下の小三腕44例は、A∞の範囲max≥7とは別に保持する。六腕・七腕の側からA∞を証明する循環はない。

## 前版からの改善

- A∞の証明を本文へ統合し、共通の道・反転・挿入の重複を整理した。
- 七腕では最大の三重反復長を選び、二つの特殊分岐と固定offset核を除いた。
- 小基底は殻の三本を先に選ぶ短い論証へ替え、1716型の計算機による被覆を証明前提から外した。
- 既存の一腕α核を二段接合し、offset現物を24個から22個に減らした。

本文の簡潔さを優先し、直接例を減らすためだけの短腕族は追加していない。六腕の追加現物69個は保持する。七腕の現物は89個から86個（小α44＋残余offset22＋直接20）になった。A∞本体の37現物と306レシピは別枠で変更していない。

配布JSONには111役割レコード、重複する実配列をまとめると110種類を収める。小三腕44例は六腕と七腕で共有する。旧版と元添付は別の場所に保持した。

## 全体の分量

共通補題・A∞・六腕・七腕・有限証書をすべて含め、**20頁**に統合した。前版の全内容を同じA4・10pt・22mm余白・目次設定で再組版した22頁から2頁、約9％減である。A∞を別冊へ外して数えていない。Markdown原稿は36,338文字から35,157文字へ約3.25％減った。数学記法のTeX化も文字数に影響するため、頁数と原稿数の両方を記録した。

## 実行と検証

標準Pythonだけで、任意の六つまたは七つの正整数腕長から実ラベリングを作れる。各列はハブの隣から葉へ向かい、入力腕順を保つ。

```sh
python -B src/construct.py 1 2 2 31 37 41 --output /tmp/six_labels.json
python -B src/construct.py 2 2 2 6 6 6 19 --output /tmp/seven_labels.json
python -B src/verify.py --input /tmp/seven_labels.json
python -B src/verify.py --full --report checks/verification.json
python -B vendor/ainf37/independent_check.py
```

構成器は配布内の縮約証書とA∞だけを読み、元Fableライブラリや探索ソルバーを必要としない。検査器はラベル・辺差・α条件・offset区間・腕順序を構成器の検査関数とは独立に確認する。

最大腕12以下の全44,200組に加え、境界・乱択・30万辺の例と負テストを検査する。有限現物と本文が指定する有限集合の照合は証明の一部である。無限域は本文の全整数論証による。Lean形式化は未実施。

## 原資料と再現

`references/ainf37/` は元の独立版A∞の原稿・PDF・名前付き証書であり、参照コピーとして変更せず保持した。`vendor/ainf37/` の実装と証書も原物のまま。原稿にある `03_CERTIFICATE_AND_CHECKS/` は本配布の `vendor/ainf37/` に対応する。原配布全体の監査 `VERIFY_RESULT.py` に代えて、上記の独立検査器を実行する。

`certificates/export_core.py` は元の展開資料から同じ縮約証書を再抽出する任意の補助ツールで、通常の構成・検証には不要。出典とコピーの範囲は `certificates/source_copies.json`、`reference_copies.json` と各現物の `provenance` に記録した。

検証・別レビュー・分量比較の記録は `checks/`、整理内容は `05_CHANGES_AND_VERIFICATION_JA.md`、最終配布ファイルのハッシュは `SHA256SUMS` にある。PDFの再生成はPandoc、XeLaTeX、Noto CJKフォントを用意し、`python -B render.py` を実行する。
