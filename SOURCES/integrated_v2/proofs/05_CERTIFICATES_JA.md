# 有限証書と検証

有限現物は `certificates/core.json`、A∞用の証書は `vendor/ainf37/certificate_core.json` に収める。各レコードは腕長 `lengths`、ハブラベル `hub`、ハブ直後から葉への列 `arms`、offset核なら `c` を持つ。`provenance` は原資料の位置とSHA-256を示す。

## V1 証明に必要な有限命題

六腕章の $K_7,P$ を用い、昇順六つ組 $1\le s_1\le\cdots\le s_6\le7$ の924代表を20通りの三添字集合で調べる。成功は906個、失敗集合は厳密に $D_6$ の18個であり、`six_direct` のキーと一致する。実際の長さへの持ち上げは六腕章で証明した。

七腕の164核を七腕章の優先条件で分類すると、$\alpha$供給72、全等長15、二等長帯10、OP接合43、二つの一腕$\alpha$核の逐次接合2、残余22となる。最後のキー集合が `offset` と厳密に一致する。72供給の内訳は、直接$\alpha$性を確認する小三腕44個と、A∞による最大腕7の28個である。

七腕の小基底の被覆はF6と殻を先に選ぶ論証から従う。1716型の列挙は実装確認として行うが、被覆の証明前提ではない。

| 節 | 件数 | 現物の役割 |
|---|---:|---|
| `alpha_small` | 44 | 最大腕6以下、$E$外のハブ0 $\alpha$供給 |
| `six_hz` | 7 | 六腕の例外核 $K_7$ |
| `six_direct` | 18 | 六腕の直接例 $D_6$ |
| `offset` | 22 | 構成式で残るoffset核 |
| `seven_direct` | 20 | 七腕の直接例 $D_7$ |
| `fixed_offset` | 0 | 旧形式との互換用の空欄 |

七腕用の保存現物は $44+22+20=86$ 個である。小三腕44個は六腕と共有する。最大の三重反復長を選ぶため、旧版の特殊核 $O((2,2,6),7)$ は不要である。

## V2 定義照合と再現

独立検査器は構成器の検査関数を使わず、整数型、指定腕長と順序、頂点区間・辺差区間の全単射、根0、必要な$\alpha$分離、および指定キー集合との完全一致を確認する。graceful現物は頂点 $[0,q]$・差 $[1,q]$、offset核は非根 $[c+1,c+q]$・差 $[1,q]$ を対象とする。

A∞の証書は原物の37現物版を用いる。A9の19直接プロファイル・306レシピが有限域2544三つ組の残余325組を厳密に閉じる。名前付きの同じ内容は `references/ainf37/certificate_named.json` に置く。元の独立検査器は、構成器を読み込まずに有限前提と全操作を再構成する。

配布フォルダから標準Pythonで実行できる。

```text
python -B src/verify.py --full --report checks/verification.json
python -B vendor/ainf37/independent_check.py
```

上記の有限命題と現物の正しさは証明の一部である。より広い有限範囲・境界例・大規模例の出力試験は実装の確認であり、全整数性は共通補題、A∞、六腕の持ち上げ、七腕の核構成と網羅的分割による。本書は人間可読の計算機援用証明であり、Lean形式化は未実施である。
