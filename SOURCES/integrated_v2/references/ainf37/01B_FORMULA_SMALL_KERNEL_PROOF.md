# R02 完全証明：全整数の直接構成と37実物の有限核

**主定理.** 整数 `1≤a≤b≤c`、`c≥7` に対し、三腕spider `S(a,b,c)` はhub0 α-labelingを持つ。

三腕spiderとは、一本ずつの長さがa,b,cで、hub以外の頂点を共有しない三本の道である。`n=a+b+c`、`k=⌊a/2⌋+⌊b/2⌋+⌊c/2⌋` と置く。求めるラベリングはhubを0に固定し、全頂点ラベル `0,…,n`、全辺差 `1,…,n` をそれぞれ一度ずつ用い、各辺が `[0,k]` と `[k+1,n]` を結ぶものとする。

§1–7は有限種を使わず `c≥25` の全整数と `a=1,c≥7` を構成する。§8–9は `7≤c≤24` の残りを、37個の実物配列と306本の有限手順により厳密に閉じる。この有限データは証明の必須部分であり、§1–7の無限証明を置き換えるものではない。全域の判定は **COMPRESSED_CERTIFIED_CLOSED / NOVELTY_HOLD**。

必須の有限データは `03_CERTIFICATE_AND_CHECKS/certificate_core.json`（20,376 bytes）。名前付きの同一内容は `certificate_named.json`（67,193 bytes）で閲覧できる。両表現の一致と全手順を独立検証する。旧R01の証書・探索器・一般端点道の外部定理への依存はない。

## 1. 道と葉の挿入

`A(N,r)` はラベル `0,…,N−1`、臨界値 `k=⌊(N−1)/2⌋`、始点rのα道を表す。`r=0` ではジグザグ列 `(0,N−1,1,N−2,…)`。`r>0`、`N≥2r+1,N≠4r+1` では次の再帰で定める。

\[
\begin{array}{ll}
N\le4r:& A(N,r)=C_N(A(N,k-r)),\\
N\ge4r+2,\ N\ne6r+2:&
A(N,r)=(r,N-r,r-1,N-r+1,\ldots,1,N-1,0)\Vert(N-r-1-A(N-2r-1,r)),\\
N=6r+2:&
A(N,r)=(r,5r+1,r-1,5r+2,\ldots,0,6r+1)\Vert(r+1+A(4r,r)),
\end{array}
\]

ここで `C_N(x)=k−x`（低側）、`C_N(x)=N+k−x`（高側）。第一分岐は `0≤k−r<r`、他の分岐はNを厳密に減らすので辞書式順序 `(N,r)` で停止する。第一分岐の子が禁止値なら `N=4(k−r)+1` から `k−r=r` となって矛盾する。通常分岐の子が禁止値になるのは第三分岐の場合だけである。

`C_N` は各側のラベル区間を保ち、辺差dを `N−d` に変える。通常接頭部の差は `N−2r,…,N−1`、結合差は `N−2r−1`、後半内部差は `1,…,N−2r−2`。特別接頭部の差は `4r+1,…,6r+1`、結合差は `4r`、後半内部差は `1,…,4r−1`。ラベル区間は各々ちょうど分割され、低高の交互性も続く。従って全再帰がα道を与える。

辺差を高−低として加算すると、他端は `N=2u+1` なら `u−r`、`N=2u` なら `u+r`。特に禁止値 `N=4r+1` では両端がrとなるため、r>0では不可能である。

臨界値kのα木の葉が低側 `k−r` または高側 `k+1+r` にあるとする。m頂点をその先へ追加する際、旧低ラベルを固定し、旧高ラベルへmを加え、新頂点を順に

\[
k+m-A(m,r)\quad\text{または}\quad k+1+A(m,r)
\]

でラベル付けする。新ラベルは `[k+1,k+m]`、旧差は `[m+1,m+n]`、結合差はm、道内部差は `[1,m-1]`。終点公式から新葉の距離もrである。旧hub0は固定される。同じ式は長さ0の第三腕、すなわち次数2のhubから新しい第三腕を作る場合にも成立する。

従ってr=3の第三長zの種は

`E(z)={z}∪[z+7,z+12]∪[z+14,∞)`

を供給する。二つの種z,z+1があれば `[z+7,∞)` を全て供給する。

## 2. グリッドと五つの端子

行0,…,K、列0,…,H−1に対し、辺をセル `(i,j)` とする。n本のセルの和が0,…,n−1を一度ずつ取り、行0がhubで接続関係が所望のspiderなら、行のラベルi、列のラベルn−jがhub0 α-labelingを与える。

frameを `(R,C,flip)` と書き、R,Cは**元のグリッドの物理的な最大行・最大列**とする。局所セル `(x,y)` は、flipなしなら物理セル `(R+x,C+y)`、flipありなら `(R+y,C+x)` を意味する。未完成の五道の端子を、この局所座標で

`P0=row(−1), P1=row0, P2=col(−2), P3=col(−1), P4=col0`

とする。長さ0の道も許し、孤立葉、またはhubの未使用の第三接続口を表す。

**五辺則B.** 局所セル

\[
B=((1,-2),(-1,1),(2,-1),(0,2),(3,0))
\]

を加える。和は `−1,0,1,2,3`。P0,…,P4は順に新しい `col1,col2,row1,row2,row3` へ一辺伸びる。物理frameの更新は

`(R,C,false) → (R+3,C+2,true)`、

`(R,C,true) → (R+2,C+3,false)`

である。この局所軸の交換によって、端子番号は元の順序へ完全に戻る。よってBをq回付けると各一端子道はq伸び、二端子を結ぶ道は2q伸びる。`B_j` はBの最初jセルを意味する。j=2,4では物理的な両側の最大値をj/2増やし、flipは変えない。

**戻り道N.**

\[
N=((0,-1),(2,-2),(-1,2),(1,1)).
\]

和は `−1,0,1,2`。P1–P3を一辺で閉じ、P2とP0をそれぞれ一辺伸ばし、新しい中立道を一辺作る。両側の最大値を2増すと、新P0–新P3が中立道、新P1が旧P2の延長、新P2が旧P4、新P4が旧P0の延長になる。

これらの操作は旧座標を動かさず、新しい行・列をそれぞれ次の連続区間から使う。従って和の連続性、頂点の全使用、接続の追跡は局所の表示だけで保証される。

連続するセル和の接続位置も明示しておく。未完成の森林では、辺数nと物理frameは **`n=R+C−1`** を満たす。§3の三初期森林で直接成立し、B、N、B2、B4はnとR+Cを同量ずつ増すので保存される。局所和−1の最初の新セルは物理和 `R+C−1=n` を持つ。従って旧和 `0,…,n−1` の直後から新和が始まる。§4の0版はframeを各側で4,3増して9辺、1版は4,4増して10辺、Fは1,1増して4辺を加えるため、終端後は `n=R+C+1`、すなわち使用頂点数が正確にn+1となる。flipは二つの増分を交換するだけである。

## 6. 境界25を閉じる整数計算

二版の種の短い方をzとすれば、cの失敗は `c≤z+6`。一版では高々 `c≤z+13`。`c≥b` と組み合わせると、§5の各族で失敗するcの上界は次となる。

14欄の計算は一つの式にまとめられる。`b=2t+4q+C`、`z=t+q+F` と書き、二版ならL=6、一版ならL=13とする。固定差の場合はq=0である。失敗するなら

\[
2t+4q+C\le c\le t+q+F+L
\quad\Longrightarrow\quad
t+3q\le F+L-C
\quad\Longrightarrow\quad
c\le2(F+L)-C-2q\le2(F+L)-C.
\]

下表は§5のC,Fをこの最終式へ代入した値であり、有限範囲からの外挿ではない。

| 偶奇 | 腕長差の順 | 上界 |
|---|---|---|
| EE | 0,2,4+4q,6+4q | 24,22,20,14 |
| OO | 0,2,4+4q,6+4q | 23,21,19,13 |
| EO | 1,3+4q,5+4q | 19,23,17 |
| OE | 1,3+4q,5+4q | 24,22,20 |

例えばEE同長なら `2t≤c≤t+12` より `c≤24`。EOの差3+4qなら `2t+3+4q≤c≤t+13+q` より `t+3q≤10`、従って `c≤23−2q≤23`。OEの差5+4qなら `2t+6+4q≤c≤t+q+13` より `t+3q≤7`、従って `c≤20−2q≤20`。他の欄も表のb,zを代入する同じ計算である。全上界が25未満なので、a≥2の場合が全て閉じる。

## 7. 第一腕1の全域（c≥7）

`m=1+b+c`。次の四場合で直接構成する。

1. **b偶数、c>b。** `P=A(b+c+1,b/2)`。通常・特別のどちらの接頭部も0が添字bにある。そこでPを左右に分けて二腕とし、単葉mを追加する。
2. **b=c=2t。** c≥7よりt≥4。`P=A(4t+1,t+1)` を使う。そのsmall分岐は `C_{4t+1}(A(4t+1,t−1))`。内側の通常接頭部の後は `3t+1−A(2t+2,t−1)` で、後者のsmall分岐は `C_{2t+2}(A(2t+2,1))`。`A(2t+2,1)` の最初二項が `(1,2t+1)` なので、Pの添字2tは0となる。そこで二分し、単葉mを追加する。
3. **b=2r+1、c≠2b−1。** 単葉m、長さbの腕 `(m−1,1,m−2,2,…,m−r−1)`、長さcの腕 `r+c−A(c,r)` を使う。r=0なら短腕は一項m−1である。三部分のラベル区間は分割され、辺差は順に `{m}`、`[c+1,m−1]`、`[1,c]`。
4. **b=2r+1、c=2b−1。** `P=(b+c)−A(b+c+1,r+1)`。c≥7よりr≥2で、通常接頭部の最大ラベルが添字 `2(r+1)−1=b` にあるから、Pの同じ位置は0。そこで二分し、単葉mを加える。全補変換は二部集合を交換するが、両腕が奇数なので必要な低側の大きさに一致する。

二分した道に最大ラベルmの単葉を足す場合は、旧差1,…,m−1に差mが加わり、α条件とhub0は保たれる。これでa=1の全域と、a≥2,c≥25の無限領域が閉じる。

## 8. 三辺交換による有限データの共有

αラベリングのセル集合Xに対し、整数 `i,j≥0`、`d,e>0` を選び、

\[
\begin{aligned}
A&=\{(i,j+d),(i+d,j+d+e),(i+d+e,j)\},\\
B&=\{(i,j+d+e),(i+d,j),(i+d+e,j+d)\}
\end{aligned}
\]

と置く。`A⊆X` であり、`Y=(X\A)∪B` が連結なら、Yも同じn、hub0、頂点ラベル区間、辺差区間を持つ三腕αラベリングとなる。逆向きも同様である。

**証明。** AとBは同じ三行・三列を各一回使うので全頂点次数を保つ。両者のセル和はともに

\[
\{i+j+d,\ i+j+d+e,\ i+j+2d+e\}.
\]

これらは相異なり、`A∩B=∅`。元の和は重複しないため `B∩X=∅` も従う。従って辺数と全差を保存する。頂点集合と二部集合は変わらず、n+1頂点n辺の連結グラフは木である。hubだけが次数3、他の頂点は次数1または2なので、三腕spiderとなる。行0とα分離も保存される。□

連結性は必要条件であり、全ての交換に自動で成立するとは仮定しない。各有限手順の各段階で、連結性・次数・全ラベル・全差を検査する。交換後の腕順は、hubに隣接する列座標の昇順で固定する。続く葉延長は、この順序の腕番号0,1,2を用いる。交換により腕長が変わってよいが、最終的な三腕長は対象と一致する必要がある。

| 合計 | **2,544** |

一般式で供給されない三つ組は正確に325個である。有限証書は37個の実物配列を保存する。そのうち19個は最終行の直接配列、18個は他の対象に再利用する元の配列である。306本の有限手順のうち35本は保存配列から、271本は§5の式（(2,3)の直接式を含む）から生成した配列を始点に使う。後者の異なる式の指定は147個（種124、長さcまで構成したもの23）。全手順を合わせて三辺交換532回、葉延長167回、計699回を記録し、一つの手順の長さは最大7である。

各保存配列はhubの次の頂点から葉までの三列である。独立checkerは、全配列についてhub0を加えたラベルが `0,…,n` の順列、辺差が `1,…,n` の順列、各腕の奇数深さが共通cutoffより上、偶数深さがcutoff以下であることを直接検査する。式からの出発点はchecker自身の端点道・グリッド構成で再生成する。全306本の操作列を別実装で再実行し、各交換の前提と接続を検査してから対象の腕長と比較する。最後に、325個の不足集合と306本の手順・19個の直接配列の対象集合が一致することを全件検査する。

有限データの符号化は次の通りである。具体的な全数値は添付JSONに存在し、発見用探索器を必要としない。

| 項目 | 意味 |
|---|---|
| 実物 | `[name, [arm0, arm1, arm2]]` |
| 式の指定 | `[0,a,b,variant]` は§5の種、`[1,a,b,c]` は§5の長さcの構成（(2,3)も含む） |
| 直接対象 | `[a,b,c,witnessIndex]` |
| 有限手順 | `[a,b,c,sourceRef,operations]` |
| `sourceRef≥0` | 実物の添字 |
| `sourceRef<0` | 式の指定の添字 `−1−sourceRef` |
| 操作 `[0,i,j,d,e,direction]` | §8の交換。direction=0はA→B、1はB→A |
| 操作 `[1,arm,m]` | §1の葉延長 |

`compact_codec.py` はこの表示を名前付きJSONへ可逆変換する。独立checkerは同モジュールをimportせずに解読する。20,376-byte版と67,193-byte版は数理内容が完全に同一である。圧縮によって有限手順が数学的に消えたとは数えない。

これで、§1–7により全 `c≥25` が、全件検証された有限証書により全 `7≤c≤24` が覆われる。全構成はhub0、全頂点・全差の一意性、α分離、指定された三腕長を保つ。したがって主定理が成立する。□

## 再現と判定

結果ディレクトリで `python3 -B VERIFY_RESULT.py` を実行する。個別には `03_CERTIFICATE_AND_CHECKS/independent_check.py` が構成器をimportせずに数値証明を再構成し、`check_outputs.py` が公開構成器の実出力をラベリングの定義から検査する。大きな例の検査は実装の検査であり、§6の全整数論証の代用ではない。
